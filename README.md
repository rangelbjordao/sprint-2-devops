# Projeto Emotiwave

## Descrição

Este projeto é uma aplicação desenvolvida para demonstrar o deployment em uma máquina virtual utilizando Docker.
A aplicação foi provisionada em uma VM Linux no Azure, onde todas as dependências necessárias foram configuradas.

Tecnologias utilizadas:

- Docker
- Linux

---

## Arquitetura e Deployment

A aplicação foi executada em uma VM Linux provisionada no provedor de nuvem.  
O Docker foi instalado na VM e o deployment da aplicação foi realizado diretamente via Dockerfile.
